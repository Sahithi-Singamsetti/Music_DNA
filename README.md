
# 🎧 Music DNA

Discover the hidden patterns in music.

Music DNA is a machine learning-powered music discovery project that explores musical similarities, identifies patterns in audio features, and visualizes how songs relate to one another.

## Project Goals

- Explore and understand musical audio features.
- Discover groups of similar songs using unsupervised learning.
- Build an interactive map of musical similarities.
- Explore musical personalities and compare tracks.
- Create a polished, interactive music discovery experience.

## Technology

- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Plotly
- Google Colab for cloud-based experiments
- Streamlit for the interactive application

## Project Structure

- `data/` — Local data workspace; large datasets will not be stored on the laptop.
- `src/` — Reusable Python source code.
- `visuals/` — Visualizations and exported figures.
- `01_music_dna_foundations.ipynb` — Initial exploration notebook in Google Colab.
